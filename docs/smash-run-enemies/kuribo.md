**kuribo** (walker). Goomba. Walks (no hitbox); every 100 frames looks for a fighter in a box ahead; on seeing one it does a little surprised back-hop, then charges (RunL) with a contact hitbox for up to 110 frames, turning to keep chasing; then brakes and walks again. Stomped -> Collapses (squashed); killed -> flies off as a bullet that hits.

- Variations: var 1 turns at ledges (walk, run, brake); every other variation walks / runs off ledges. P0 has one entry (no per-variation tuning).
- Targeting: start (slot 41): faces get_nearest_target. Walk / charge use EnemyAiModule::check_target with param group 1 entries 0 / 1 (type 2) on a frame-modulo timer; the found fighter's x decides the turn.
