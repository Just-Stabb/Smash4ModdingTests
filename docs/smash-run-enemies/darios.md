**darios** (stationary turret). Darios (Kid Icarus Uprising). A ground turret: lands, slowly swivels its barrel (Turn motion frames set from the aim angle) toward a fighter inside its aim cone, charges (effect) and fires a sweeping beam that is an attack on the enemy itself (param P6, re-set every frame while the beam lasts), with screen shake; then cools down.

- Variations: P0 rows are indexed by the variation (var * 9 words... per-variation tuning: charge P0.f6 = 90 frames, beam P0.f8 = 120 frames, ...).
- Targeting: an aim angle (this+0x170 / +0x174) turned toward the nearest target; the shot is triggered by search_target(1) in a cone around it.
- Projectiles: none (the beam is the enemy's own attack).
- Death: HP 0 -> 6 (bullet) -> remove.
- Meshes: vmt: 0 default, 1 shoot: shoot only in state 5 (beam), default otherwise.
