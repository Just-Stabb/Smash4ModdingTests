Sm4shCloneTool draws the clones' name plates with DFMincho-SU by default (the look of the game's own plates) and
other text pictures with DFGothic-SU. You can pick another font file in the window ("Choose font file...") or on the
command line (font_plate=..., font_title=..., font_other=...).
